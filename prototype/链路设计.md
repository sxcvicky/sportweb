# 外贸出海诊断 H5 · 链路设计

> 用途：给开发照着做的链路说明。视觉和交互以 `dist/` 原型为准。
> 边界：这里只做原型和链路设计；后端、LLM、知识库、支付、部署由开发实现。

## 定位

| 项目 | 说明 |
|---|---|
| 这个页面是什么 | 外贸出海诊断：按阶段问诊 → 问题分析 → 完整建议 |
| 客户是谁 | 想做 / 正在做外贸出海的人 |
| 诊断什么 | 品类、平台、市场、成本、合规、团队与时间 |
| 给出什么 | 免费版 1 页；完整版 69 元，5–6 节 |
| 怎么给 | 提交后加企微；报告只生成一次；企微通知；退出后能回来 |
| 不承诺 | 出单、赚钱、回本 |

**对外一句话：外贸出海，先做一次诊断。**

## 一、客户链路

```text
入口选档位（4 档，自选，不做自动识别）
→ 对应分支问诊
→ 提交：诊断记录先保存，状态 pending
→ 加企微（免费，拿身份）
→ 开始生成：调用一次 LLM，产出完整报告
→ 免费版：只展示 preview，隐藏完整版内容
→ 69 元付款：只解锁 full，不重新生成
→ 企微通知 / 我的诊断
```

**两个核心原则：**

1. 报告归属到用户身份，不归属到浏览器会话。关掉页面、换设备，报告都在。
2. LLM 只调用一次，一次产出 preview + full。免费版隐藏内容，付费只解锁。

## 二、四个档位

| 档位 | 用户描述 | 诊断类型 | 问诊重点 |
|---|---|---|---|
| 还没开始 | 有想法，或手里有货，还没正式卖 | 入场诊断 | 品类、货源、预算、市场、平台、经验、风险 |
| 刚开始 | 店铺/账号已开，单量还不稳定 | 起步诊断 | 平台、上线时间、月单量、流量、转化、毛利、退货、卡点 |
| 已经在做 | 有稳定单量，卡在增长、利润或合规 | 经营诊断 | 月销、订单、SKU、广告 ROI、退货、合规、供应链、团队 |
| 公司化/多平台 | 有团队、多平台或多市场，卡在体系、供应链或组织 | 体系诊断 | 多平台、多市场、组织、供应链、库存、合规、数据 |

- 入口由用户自己选档位，不做自动分类。
- 还没开始沿用 12 题入场表；其他三档使用分支问诊。
- 档位写入诊断记录，后续报告、提示词、知识库检索都用它。

## 三、报告两档

| 项目 | 免费版 | 完整版（69 元） |
|---|---|---|
| 生成 | 同一次 LLM 输出 | 同一次 LLM 输出 |
| 长度 | 1 页 preview | 5–6 节 full |
| 内容 | 结论 + 3 个发现 + 下一步 | 结论与假设、现状与瓶颈、关键判断、30/60/90 计划、风险与止损、下一步 |
| 交付 | 生成后直接看 | 付款后解锁 |
| 人工 | 不人工审核 | 不人工审核 |
| 30 分钟解读 | 不含 | 不含，只卖报告 |

### 各档完整版重点

| 档位 | 免费版 | 69 完整版 |
|---|---|---|
| 还没开始 | 该不该做、3 个发现、7 天第一步 | 平台/市场选择、启动成本、合规清单、7/30/90 计划、风险与止损 |
| 刚开始 | 阶段判断、3 个卡点、1 个动作 | 单量、流量、转化、毛利、30/60/90 计划、放量或止损 |
| 已经在做 | 3 个瓶颈、1 个优先动作 | 利润结构、广告 ROI、退货、合规、供应链、60/90 计划、放量或止损 |
| 公司化/多平台 | 3 个体系缺口、1 个优先动作 | 多平台/多市场、组织、供应链、库存、合规、资源配置、90 天优先级 |

## 四、身份、异步、持久化

1. **企微放在提交后**：用户填完点提交，再出现企微；加企微后开始生成。
2. **待加企微状态**：诊断记录先保存为 `pending`；用户退出后，从“我的诊断”还能看到，点“去加企微”继续。
3. **身份锚点**：企微外部联系人 + 报告 access token。客户用微信扫码即可，不需要安装企微。
4. **服务端存报告**：诊断记录、报告状态、内容、订单、时间都存数据库；不依赖浏览器 localStorage。
5. **状态**：`pending / generating / ready / failed`；`paid` 单独表示是否解锁完整版。
6. **一次生成**：`generating` 开始后只调用一次 LLM，产出 `preview + full`；生成完 `ready`。
7. **退出再回来**：从企微消息或 H5“我的诊断”打开；报告按用户身份找回。
8. **支付只解锁**：69 元付款回调把 `paid` 置为 true；不重新生成、不重新调用 LLM。
9. **失败处理**：重试；仍失败标记 failed，保留订单和客服入口。
10. **链接**：长期有效、不可猜测、绑定用户；正式版加过期/访问码/撤回。

## 六、数据与状态

**诊断记录：**
`id`、`token`、`uid`、`stage`、`customer`、`source`、`createdAt`、`updatedAt`、`answers`、`reportStatus`、`reportStartedAt`、`reportReadyAt`、`paid`、`report`、`notes`

**报告对象：**
`report = { preview, full }`。一次生成同时产出；免费版只读 `preview`，付费后读 `full`。

**状态：**
`pending`（待加企微）、`generating`（生成中）、`ready`（已生成）、`failed`（失败）。

**统计事件：**
`page_view`、`stage_select`、`form_start`、`step_complete`、`submit`、`lead_page_view`、`lead_continue`、`report_start`、`report_view`、`cta_deep_report`、`pay_complete`、`copy_wechat`

**设置：**
`wechatId`、`wechatLabel`、`price`（69）

## 七、LLM、知识库、提示词

- **只调用一次**：一次输出 `preview` + `full`；免费版隐藏 full，付费只解锁。
- **阶段提示词**：4 个阶段各一套；行业通过知识库检索注入，不做 4×N 套 prompt。
- **知识库分层**：通用层（市场/平台/合规/成本/物流）+ 行业层（品类事实卡）+ 阶段层（判据/瓶颈/动作库）。
- **检索**：按阶段 + 行业 + 市场 + 平台过滤，取 top-k；报告引用来源。
- **无人审核**：平台规则、合规、税率必须引用知识库；schema 校验不过就重生成或走兜底模板。
- **不承诺**：出单、赚钱、回本；不适合直接劝退。
- **测试**：每个阶段至少 3 个测试案例，验证一次生成同时有 preview/full，免费隐藏、付费解锁。

## 八、业务规则

1. 入口四档，用户自选；不做自动识别。
2. 企微放在提交后；留客资免费。
3. 免费版 1 页；完整版 69 元，只卖报告，不含 30 分钟解读。
4. 报告只生成一次；免费版隐藏部分；69 元只解锁，不重新调用。
5. 报告异步生成，可以退出；企微通知；下次回来报告还在。
6. 不承诺出单、不承诺赚钱、不承诺回本。
7. 不适合的直接劝退，不卖完整版。
8. 不卖课、不做代运营、不用“0 元开店/躺赚/无货源”做宣传。
9. 公域内容不写网址、微信号、二维码、电话；按平台组件承接。
10. 报告只做判断和建议，不替代税务、法律、报关等持牌服务。
11. 客户信息只用于诊断和交付；不向第三方出售；可要求删除。

## 九、原型里哪些是模拟的

| 原型做法 | 开发要替换成 |
|---|---|
| 企微二维码占位块 | 企微活码；可长期使用、可更换 |
| 收款码占位块 | 微信/支付宝商户收款码；支付回调 |
| 浏览器 localStorage | 数据库 + 服务端接口 |
| 5 秒模拟生成 | 队列 + LLM + 知识库；一次生成 preview+full |
| 模板报告内容 | 分支提示词 + 知识库生成的报告 |
| 随机 access token | 不可猜测的唯一链接 + 访问控制 |
| 模拟付款按钮 | 微信支付回调自动解锁 |
| 旧后台演示 | 新的诊断记录/报告/订单后台 |
| 本地统计事件 | 服务端埋点与报表 |

## 十、开发验收

1. 四档入口可选，档位写入诊断记录。
2. 提交后先保存诊断，再出现企微；加企微后开始生成。
3. 用户退出后，从“我的诊断”能看到 pending 并继续加企微。
4. 一次 LLM 调用同时产出 preview + full。
5. 免费版 1 页，隐藏完整版内容；完整版 69 元 5–6 节。
6. 付款只解锁 full，不重新生成、不重新调用 LLM。
7. 生成完企微通知；从企微或“我的诊断”能回来，报告还在。
8. 平台规则/合规/税率有知识库引用；无来源的内容不输出。
9. 不适合的客户直接劝退，不卖完整版。
10. 管理端能看诊断记录、报告状态、付款和交付记录。

## 十一、视觉与设备

- 客户侧手机优先，按 390px 宽设计；桌面居中，最大 520px。
- 后台按 1440px 宽设计。
- 风格：纸张、账单、印章；不做 SaaS 蓝紫渐变；不做假案例和收益承诺。
- 页面只出现客户语言：品类、预算、平台、成本、风险；技术字段藏起来。
